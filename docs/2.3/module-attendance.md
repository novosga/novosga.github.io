# Módulo de Atendimento

https://github.com/novosga/attendance-bundle

A partir da versão 2.3, as configurações de comportamento do atendimento (intercalação de senhas prioritárias e fura-fila) podem ser sobrescritas individualmente por usuário, permitindo que cada atendente tenha configurações que se sobrepõem às configurações globais do sistema.
